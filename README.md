# The Files v3.0 — Modern Documentary Platform

نسخة جديدة بالكامل بأسلوب منصة وثائقية حديثة.

## أهم التغييرات
- واجهة رئيسية سينمائية.
- هيدر شفاف يتحول عند التمرير.
- قسم أحدث تحقيق.
- سلايدر أفقي للملفات.
- تصنيفات.
- بحث شامل.
- صفحات القضايا على شكل صفحة فيلم.
- Tabs: نظرة عامة، Timeline، Evidence، Sources، Theories، Gallery.
- Lightbox للصور.
- تصميم Responsive.

## الرفع
ارفع كل محتويات هذا المجلد إلى جذر مستودع `the-files` واستبدل الملفات القديمة.

## إضافة فيديو YouTube
داخل صفحة القضية، استبدل مربع `video-box` بكود iframe الخاص بيوتيوب.

## إضافة المصادر
استبدل روابط `href="#"` بروابط المصادر الحقيقية.
